# ClipViral ONE APP - No Backend, Real Cut, USA Views

**ONE APP single file PWA - No backend needed, works on phone forever**

## How to get APK from GitHub:

### Method 1 - Auto APK Build (Easiest - APK from GitHub Actions):
1. Fork this repo or upload these files to your GitHub repo:
   - `index.html` (ONE APP)
   - `manifest.json`
   - `package.json`
   - `capacitor.config.json`
   - `.github/workflows/build-apk.yml`
2. Go to repo → Actions tab → You will see "Build APK from ONE APP PWA" running
3. Wait 3-5 minutes → Click the run → Scroll down to Artifacts → Download `clipviral-one-app-apk`
4. You get `app-debug.apk` - Install on Android phone - Real APK!

Also auto-creates Release with APK in Releases tab.

### Method 2 - PWA Install (No APK needed, works like native app):
1. Enable GitHub Pages: Settings → Pages → Source: main branch / root → Save
2. Open your GitHub Pages link `https://yourname.github.io/repo/` on phone
3. Add to Home Screen → Now it's an app icon, works offline forever

### Method 3 - PWABuilder APK:
1. Get GitHub Pages link from Method 2
2. Go to pwabuilder.com → Paste link → Build → Download APK
